🔬 Project Information

Astronaut Health Guardian is a student project demonstrating how user-entered measurements can be organised and displayed in a dashboard.

The flags shown by this demo are simplified educational prompts, not validated medical thresholds. A result marked “No demo flag” does not establish that someone is healthy. Actual health concerns should be discussed with a qualified healthcare professional.
